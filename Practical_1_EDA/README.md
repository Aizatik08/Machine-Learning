# Практическая работа №1 — Первичный анализ данных (EDA)

## Цель

Выполнить первичный анализ датасета Titanic, изучить его структуру,
типы признаков, пропуски, статистические характеристики и визуализации.

## Датасет

Titanic Dataset — информация о пассажирах корабля Titanic.

Источник:
https://github.com/datasciencedojo/datasets/blob/master/titanic.csv

## Структура проекта

- data/ — исходный датасет
- notebooks/ — Jupyter Notebook с анализом
- README.md — описание проекта

## Используемые библиотеки

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter

## Окружение

Используется venv — стандартное виртуальное окружение Python.
Оно позволяет изолировать библиотеки проекта от глобального Python.

## Выполненные этапы

1. Загрузка данных
2. Изучение размера таблицы
3. Определение типов данных
4. Анализ пропусков
5. Базовые статистики
6. Построение визуализаций
7. Формулирование наблюдений
